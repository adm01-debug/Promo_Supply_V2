## 1. Nova Solicitação de Compra

**Responsável:** Solicitante  
**Quando usar:** Ao criar uma nova requisição no sistema

### Antes de Criar

- [ ] Verifiquei se já não existe solicitação similar em andamento
- [ ] Consultei o estoque/almoxarifado
- [ ] Tenho a especificação técnica do item/serviço
- [ ] Sei qual o centro de custo/departamento
- [ ] Tenho ideia do valor estimado (cotação prévia ou histórico)

### Campos Obrigatórios

- [ ] **Título:** Descritivo e objetivo (ex: "Compra de 100 resmas de papel A4")
- [ ] **Tipo:** Material / Serviço / Equipamento / Urgente / Contrato
- [ ] **Quantidade:** Valor numérico correto
- [ ] **Unidade:** UN / CX / KG / MT / HR / etc.
- [ ] **Data de necessidade:** Data realista (considerar lead time)
- [ ] **Valor estimado:** Baseado em referência de mercado
- [ ] **Justificativa:** Motivo da compra

### Campos Recomendados

- [ ] Categoria do item
- [ ] Centro de custo
- [ ] Departamento solicitante
- [ ] Observações técnicas
- [ ] Anexos (especificações, fotos, desenhos)

### Após Criar

- [ ] Conferi o número gerado (SOL-XXXX)
- [ ] Verifiquei se os dados estão corretos
- [ ] Acompanho a aprovação

## 2. Análise de Solicitação (Aprovador)

**Responsável:** Coordenador / Gerente  
**Quando usar:** Ao receber solicitação para aprovação

### Verificações de Conformidade

- [ ] O título está claro e compreensível?
- [ ] A justificativa é adequada?
- [ ] O tipo selecionado está correto?
- [ ] A quantidade faz sentido?
- [ ] A data de necessidade é factível?

### Verificações Financeiras

- [ ] O valor estimado está dentro da realidade de mercado?
- [ ] Há orçamento disponível no centro de custo?
- [ ] O valor está dentro da minha alçada de aprovação?
- [ ] Essa compra é prioritária neste momento?

### Verificações Estratégicas

- [ ] Essa compra está alinhada com os objetivos do departamento?
- [ ] Existe possibilidade de consolidar com outras demandas?
- [ ] Há alternativas mais econômicas?

### Decisão

- [ ] **APROVAR:** Todos os critérios atendidos
- [ ] **DEVOLVER:** Solicitar ajustes/complementos
- [ ] **REJEITAR:** Registrar motivo da rejeição

## 3. Coleta de Cotações

**Responsável:** Comprador  
**Quando usar:** Ao iniciar processo de cotação

### Preparação

- [ ] Li e entendi a especificação da solicitação
- [ ] Identifiquei a categoria do item
- [ ] Consultei o cadastro de fornecedores ativos
- [ ] Verifiquei histórico de compras similares

### Seleção de Fornecedores

- [ ] Selecionei no mínimo 3 fornecedores (para valores > R$ 1.000)
- [ ] Selecionei no mínimo 5 fornecedores (para valores > R$ 10.000)
- [ ] Incluí fornecedores com bom histórico
- [ ] Considerei sugestões da IA (se disponível)

### Envio da Solicitação de Cotação

- [ ] Preparei documento com especificações claras
- [ ] Informei quantidade necessária
- [ ] Informei prazo para resposta
- [ ] Informei local de entrega
- [ ] Enviei por e-mail/WhatsApp/Portal

### Acompanhamento

- [ ] Registrei data de envio
- [ ] Agendei follow-up para 48h
- [ ] Documentei contatos realizados

---

## 4. Registro de Cotação

**Responsável:** Comprador  
**Quando usar:** Ao receber proposta do fornecedor

### Dados Básicos

- [ ] **Fornecedor:** Selecionado corretamente no sistema
- [ ] **Valor unitário:** Conforme proposta
- [ ] **Quantidade:** Conforme solicitado
- [ ] **Valor do frete:** Incluído ou separado?
- [ ] **Desconto:** Se houver, registrar percentual

### Condições Comerciais

- [ ] **Prazo de entrega:** Em dias úteis
- [ ] **Validade da proposta:** Mínimo 15 dias
- [ ] **Condição de pagamento:** 30/60/90 dias, à vista, etc.
- [ ] **Garantia:** Se aplicável

### Documentação

- [ ] Anexei a proposta comercial (PDF/imagem)
- [ ] Registrei observações relevantes
- [ ] Verifiquei se todos os itens estão contemplados

### Conferência Final

- [ ] O valor total calculado está correto?
- [ ] A cotação está dentro da validade?
- [ ] Não há pendências de informação?

## 5. Análise e Seleção de Cotação

**Responsável:** Comprador / Coordenador  
**Quando usar:** Ao comparar cotações recebidas

### Análise Quantitativa

- [ ] Comparei os valores unitários
- [ ] Considerei o custo do frete
- [ ] Calculei o valor total final de cada proposta
- [ ] Verifiquei os prazos de entrega
- [ ] Analisei as condições de pagamento

### Análise Qualitativa

- [ ] Verifiquei o score/histórico do fornecedor
- [ ] Consultei entregas anteriores (pontualidade)
- [ ] Verifiquei ocorrências ou reclamações
- [ ] Considerei a capacidade de atendimento

### Verificações de Risco

- [ ] O preço muito baixo não é suspeito?
- [ ] O fornecedor tem capacidade de entregar?
- [ ] A empresa está regular (CNPJ ativo)?
- [ ] Não há conflito de interesse?

### Decisão

- [ ] Documentei a justificativa da escolha
- [ ] O melhor custo-benefício foi selecionado
- [ ] Registrei no sistema a cotação vencedora
- [ ] Notifiquei o coordenador (se necessário)

## 6. Emissão de Pedido

**Responsável:** Comprador  
**Quando usar:** Após aprovação da cotação

### Dados do Pedido

- [ ] Vinculei à solicitação original
- [ ] Vinculei à cotação aprovada
- [ ] Fornecedor correto selecionado
- [ ] Valores conferem com a cotação

### Informações de Entrega

- [ ] Endereço de entrega correto e completo
- [ ] Responsável pelo recebimento informado
- [ ] Horário de funcionamento informado
- [ ] Telefone de contato atualizado

### Condições Comerciais

- [ ] Condição de pagamento confirmada
- [ ] Prazo de entrega acordado
- [ ] Observações importantes incluídas

### Itens do Pedido

- [ ] Todos os itens estão listados
- [ ] Quantidades corretas
- [ ] Valores unitários corretos
- [ ] Descrições claras

### Finalização

- [ ] Revisei todo o pedido antes de emitir
- [ ] Gerei o número do pedido (PED-XXXX)
- [ ] Enviei o pedido ao fornecedor
- [ ] Confirmei recebimento do pedido pelo fornecedor
- [ ] Atualizei o status no sistema

## 7. Acompanhamento de Entrega

**Responsável:** Comprador  
**Quando usar:** Durante o período entre pedido e entrega

### Monitoramento Inicial (D+1)

- [ ] Fornecedor confirmou o pedido?
- [ ] Prazo de entrega está correto?
- [ ] Há código de rastreamento?

### Monitoramento Contínuo

- [ ] Verificar status do rastreamento (se houver)
- [ ] Atualizar status no sistema (em_transito)
- [ ] Comunicar solicitante sobre previsão

### Alertas

- [ ] Pedido atrasado? Contatar fornecedor imediatamente
- [ ] Problemas informados? Registrar ocorrência
- [ ] Necessidade de reagendamento? Atualizar sistema

### Pré-Entrega

- [ ] Confirmar data/horário da entrega
- [ ] Avisar responsável pelo recebimento
- [ ] Disponibilizar cópia do pedido para conferência

## 8. Conferência de Recebimento

**Responsável:** Responsável pelo recebimento / Comprador  
**Quando usar:** No momento da chegada do material

### Conferência Visual

- [ ] Embalagem está íntegra?
- [ ] Não há sinais de danos externos?
- [ ] O volume confere com o esperado?

### Conferência Documental

- [ ] Nota fiscal presente?
- [ ] Dados da NF conferem com o pedido?
- [ ] CNPJ do fornecedor correto?
- [ ] Valores da NF conferem?

### Conferência Física

- [ ] Quantidade recebida = quantidade do pedido?
- [ ] Especificações do produto conferem?
- [ ] Qualidade aparente OK?
- [ ] Prazo de validade (se aplicável) adequado?

### Registro no Sistema

- [ ] Atualizei status para "Entregue" ou "Parcial"
- [ ] Registrei data de entrega real
- [ ] Registrei quantidade efetivamente recebida
- [ ] Anexei canhoto/comprovante de entrega

### Em Caso de Problemas

- [ ] Não aceitar mercadoria danificada
- [ ] Fotografar problemas encontrados
- [ ] Registrar ocorrência no sistema
- [ ] Comunicar comprador imediatamente
- [ ] Devolver com ressalva na NF (se aceitar parcial)

## 9. Registro de Pagamento

**Responsável:** Financeiro / Comprador  
**Quando usar:** Após confirmação de recebimento

### Pré-requisitos

- [ ] Pedido está com status "Entregue"?
- [ ] Nota fiscal foi recebida e validada?
- [ ] Não há pendências de qualidade?

### Dados do Pagamento

- [ ] Vinculei ao pedido correto
- [ ] Fornecedor está correto
- [ ] Valor confere com a NF
- [ ] Data de vencimento calculada corretamente

### Informações da Nota Fiscal

- [ ] Número da NF registrado
- [ ] Chave da NF-e registrada (se eletrônica)
- [ ] NF anexada ao sistema (PDF/imagem)

### Forma de Pagamento

- [ ] Boleto / PIX / Transferência / Cartão / Cheque
- [ ] Dados bancários corretos (se transferência)
- [ ] Código de barras conferido (se boleto)

### Finalização

- [ ] Observações relevantes incluídas
- [ ] Pagamento gerado (PAG-XXXX)
- [ ] Enviado para aprovação (se necessário)

---

## 10. Aprovação de Pagamento

**Responsável:** Coordenador / Gerente / Financeiro  
**Quando usar:** Ao aprovar pagamento pendente

### Verificações Documentais

- [ ] Nota fiscal está anexada?
- [ ] Valores da NF conferem com o pagamento?
- [ ] O pedido foi realmente entregue?
- [ ] Não há reclamações pendentes?

### Verificações Financeiras

- [ ] O valor está dentro da minha alçada?
- [ ] Há saldo disponível para pagamento?
- [ ] A data de vencimento está correta?
- [ ] Há antecipação que justifique?

### Verificações de Conformidade

- [ ] O fornecedor está com CNPJ regular?
- [ ] Não há débitos pendentes com este fornecedor?
- [ ] O processo seguiu o fluxo correto?

### Decisão

- [ ] **APROVAR:** Liberar para pagamento
- [ ] **DEVOLVER:** Solicitar correções
- [ ] **REJEITAR:** Documentar motivo

## 11. Cadastro de Fornecedor

**Responsável:** Comprador / Cadastro  
**Quando usar:** Ao incluir novo fornecedor no sistema

### Dados Básicos

- [ ] **Razão Social:** Conforme cartão CNPJ
- [ ] **Nome Fantasia:** Se houver
- [ ] **CNPJ:** Válido e ativo
- [ ] **Inscrição Estadual:** Se aplicável

### Endereço

- [ ] CEP correto
- [ ] Logradouro completo
- [ ] Número e complemento
- [ ] Bairro, cidade e estado

### Contatos

- [ ] Telefone principal
- [ ] E-mail comercial
- [ ] Nome do contato principal
- [ ] WhatsApp (se disponível)

### Dados Bancários

- [ ] Banco
- [ ] Agência
- [ ] Conta corrente
- [ ] Tipo de conta (PJ)
- [ ] Titular confere com razão social

### Documentação

- [ ] Cartão CNPJ anexado
- [ ] Contrato Social (se solicitado)
- [ ] Certidões negativas (se solicitado)
- [ ] Referências comerciais (se solicitado)

### Validação

- [ ] CNPJ consultado na Receita Federal
- [ ] Situação cadastral: ATIVA
- [ ] Não há impedimentos (CADIN, protestos, etc.)

## 12. Fechamento Mensal

**Responsável:** Coordenador / Financeiro  
**Quando usar:** No último dia útil do mês

### Solicitações

- [ ] Todas as solicitações do mês foram processadas?
- [ ] Há solicitações pendentes de aprovação?
- [ ] Solicitações canceladas foram justificadas?

### Cotações

- [ ] Cotações expiradas foram tratadas?
- [ ] Não há cotações pendentes de análise?

### Pedidos

- [ ] Todos os pedidos têm status atualizado?
- [ ] Entregas pendentes foram acompanhadas?
- [ ] Atrasos foram registrados e comunicados?

### Pagamentos

- [ ] Todos os pagamentos do mês foram registrados?
- [ ] Não há pagamentos atrasados sem justificativa?
- [ ] Previsão do próximo mês está atualizada?

### Indicadores

- [ ] KPIs do mês foram calculados
- [ ] Relatório mensal foi gerado
- [ ] Desvios foram analisados
- [ ] Ações corretivas foram registradas

### Fornecedores

- [ ] Score dos fornecedores atualizado
- [ ] Ocorrências foram tratadas
- [ ] Cadastros novos foram validados

### Documentação

- [ ] Backup dos documentos realizado
- [ ] Arquivos organizados por período
- [ ] Relatório enviado à gestão

## 📎 Notas de Uso

### Legenda
- [ ] = Item pendente de verificação
- [x] = Item verificado/concluído

### Dicas
1. Imprima o checklist relevante para a tarefa do dia
2. Marque cada item conforme for concluindo
3. Não pule etapas mesmo em situações urgentes
4. Em caso de dúvida, consulte o POP correspondente
5. Guarde os checklists preenchidos para auditoria
